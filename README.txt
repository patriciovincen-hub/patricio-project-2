KABANKALAN CATHOLIC COLLEGE WEBSITE
==================================

Open index.html in a browser or open this folder in Visual Studio Code.

Main pages:
- index.html: Home
- about.html: About KCC
- courses.html: Course/program overview
- trainers.html: Administrators (file name and href intentionally retained)
- events.html: KCC events and campus activities
- pricing.html: Tuition and fee inquiry guide
- contact.html: KCC location and contact details

Important content notes:
- Navigation href values were retained (including trainers.html) as requested.
- KCC information is based on publicly available KCC website and KCC-related publications.
- Tuition amounts are not published as made-up prices. The Pricing page explains that students should request the current official assessment from the Registrar/Finance Office.
- Some administrator positions were reported in a 2025 institutional publication; please verify current officeholders before submitting this as an official institutional directory.
- KCC campus/emblem photos are linked to publicly indexed image sources and require an internet connection to display.
